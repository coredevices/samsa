# Oracle disputes

No disputes have been approved. All 100,000 sampled ALU cases from Unicorn
2.1.4 agree with Samsa and the independent integer model. This result applies
only to the sampler's documented ALU subset, not the entire instruction set.

Each future entry must name the exact encoding, operands, Unicorn version,
ARM DDI 0403E pseudocode reference, expected behavior, and one-line reason.
UNPREDICTABLE encodings must be excluded by the sampler, not allow-listed.
